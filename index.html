Mengenal Dasar HTML dan Struktur Dokumen

Dipublikasikan oleh saya • 12 November 2026

HTML (HyperText Markup Language) adalah bahasa tandai standar yang digunakan untuk membuat halaman web. Dengan HTML, kita bisa menyusun judul, pargraf, gambar, tautan, hingga tabel agar sebuah website memiliki kerangka yang jelas.


Setiap dokumen HTMk memerlukan struktur dasar seperti tag `<html>`, `<head>`, dan `<body>` agar dapat dibaca dengan baik oleh peramban web (*browser*).

Mengatur Tampilan dengan CSS dan Media Query

Dipublikasikan oleh saya • 12 November 2026

Cascading Style Sheets (CSS) berfungsi untuk mempercantik tampilan halaman web. Melalui CSS, kita bisa mengatur warna, jenis huruf, jarak, hingga tata letak menggunakan Flexbox.


Selain itu, dengan fitur Media Query, kita bisa mengubah tata letak halaman secara otomatis agar tetap rapi dan mudah dibaca baik saat diakses lewat laptop maupun layar *smartphone*.
